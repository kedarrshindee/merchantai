    TRANSPARENCY & CONTROL
    Built to demonstrate. Designed for human judgment.
    What the demo checks
    Seven required fields and four required document categories contribute equally to completeness. PAN and GSTIN are checked for format only. Account suffixes must contain four digits, years must be a whole number from 0 to 100, and supplied website addresses must use HTTP or HTTPS. A normalized name-similarity score below 62%, a listed enhanced-review category, or zero years of operation raises an attention flag.
    Human-in-the-loop
    Analysis can suggest ready for review, request information, or enhanced human review. Only the human-review buttons record a decision, and every decision requires a reason. Changing an application clears its prior analysis and decision.
    Session-only data
    Application details, selected filenames, and the demonstration audit trail stay in page memory and disappear when the page reloads. This is not an authenticated or tamper-proof review system.
    Academic disclaimer
    Not affiliated with or deployed by YES BANK. This demonstration does not perform real KYC, AML, sanctions, credit, or regulatory verification and must not be used for financial decisions. Use fictional data only. Production use would require verified data services, access controls, privacy safeguards, and durable audit records.
