# MerchantAI

Academic merchant-onboarding demonstration. Not affiliated with YES BANK. Fictional data only; no actual KYC, AML, sanctions or regulatory verification.

## Features

- Four fictional application scenarios.
- Explainable completeness, format and name consistency checks.
- Human review with mandatory reasons and a session audit trail.
- Research references and RTOCF prompt.
- Responsive, dependency-free static website. Data stays in page memory and resets on reload.

## GitHub Pages

Upload the files in this folder to the root of a public GitHub repository. In Settings → Pages, choose Deploy from a branch, select main and / (root), and save. GitHub shows the live URL when deployment completes.

No API keys, Python runtime or build step is needed.
